# 기록물철 라벨 생성기 v2

> v1(`../record-label/`)과 독립된 사본입니다. 설정 저장 키도 분리되어 v1에 영향을 주지 않습니다.

`기록물철_라벨_생성기_v2.html`을 크롬/엣지로 열고 사업완료 명단 엑셀을 올리면
명단 순서대로 아래 3종을 만들어 인쇄(PDF 저장)합니다. 인터넷 연결 없이 동작하며, 엑셀 내용은 PC 밖으로 전송되지 않습니다.

| 출력물 | 단위 | 규격(원본 한글 서식 실측) |
| --- | --- | --- |
| 기록물철 표지 | 농가 1곳당 A4 1장 | 121.0×60.8mm, 가로 가운데, 위에서 52.3mm(원본 1번째 칸, 설정에서 2·3번째 칸 선택 가능) |
| 색인목록 | 상자 1개당 1장 | 외곽 188×258mm, 농가별 생년월일·사업소재지(없으면 주소)·연락처·사업량·사업비·계좌 |
| 상자 라벨 | 상자 1개당 1개 | 93.1×92.0mm(원본 세로의 80%), A4당 2×2 |

- 성명 열과 2단 헤더(예: `사업완료 내역(천원) › 계`)를 자동 인식합니다. 금액은 사업완료 내역을 우선 쓰고, 비어 있으면 교부결정 내역을 씁니다.
- 단위과제·보존기간은 화면의 "사업 ↔ 단위과제 연계표"로 자동 입력합니다. 기록관리기준표와 대조해 수정하세요.
- 인쇄 시 배율 100%, 여백 "없음"으로 설정하세요. 프린터 오차는 "인쇄 위치 보정"에서 mm 단위로 맞춥니다.

수정 후 재빌드: `npm install xlsx@0.18.5 && node record-label/build.mjs`

## v2 변경 사항
- 여러 시트가 있는 엑셀을 올리면 왼쪽 **시트 목록**에서 시트를 눌러 사업별로 관리합니다. 체크한 시트는 "전체"에서 함께 인쇄합니다.
- 시트마다 서식이 달라도 헤더 이름으로 열을 찾습니다(헤더 1~4줄, 그룹 제목 병합, 원/천원, 국비·도비 분리, 계만 있는 사업비, 날짜 형식 생년월일).
- 사업비는 완료·정산 > 변경 > 선정(오른쪽) 순으로 우선 사용하고, 세부내역·산출 칸은 쓰지 않습니다.
- 읍면동 열이 있으면 생산기관 읍면(표선면)만, 진행상황 열이 있으면 포기·후순위·제외·예정 등을 기본으로 인쇄에서 뺍니다(체크로 변경 가능).
- 같은 농가 목록의 시트(본 명단과 세부내역)는 뒤 시트를 전체 인쇄에서 자동 제외합니다.
- 상자 라벨은 기본 5농가마다 1개로 나누고(사업이 바뀌면 새 상자), A4 한 장에 4개씩 채워 인쇄합니다. 색인목록도 상자 단위로 함께 나뉩니다.
- 기록물철 표지 위치를 원본보다 30mm 아래로 이동(1번째 칸 기준 위에서 82.3mm).
- 시트마다 "열 인식 결과 확인"에서 어느 열을 읽었는지 확인할 수 있습니다.
