# 기록물철 라벨 생성기

`기록물철_라벨_생성기.html`을 크롬/엣지로 열고 사업완료 명단 엑셀을 올리면
명단 순서대로 아래 3종을 만들어 인쇄(PDF 저장)합니다. 인터넷 연결 없이 동작하며, 엑셀 내용은 PC 밖으로 전송되지 않습니다.

| 출력물 | 단위 | 규격(원본 한글 서식 실측) |
| --- | --- | --- |
| 기록물철 표지 | 농가 1곳당 1장 | 121.0×60.8mm, A4당 3개, 가로 가운데, 위에서 52.3/121.9/191.4mm |
| 색인목록 | 상자 1개당 1장 | 외곽 188×258mm, 농가별 생년월일·주소·연락처·사업소재지·사업량·사업비·계좌 |
| 상자 라벨 | 상자 1개당 1개 | 93.1×115.0mm, A4당 2×2 |

- 성명 열과 2단 헤더(예: `사업완료 내역(천원) › 계`)를 자동 인식합니다. 금액은 사업완료 내역을 우선 쓰고, 비어 있으면 교부결정 내역을 씁니다.
- 단위과제·보존기간은 화면의 "사업 ↔ 단위과제 연계표"로 자동 입력합니다. 기록관리기준표와 대조해 수정하세요.
- 인쇄 시 배율 100%, 여백 "없음"으로 설정하세요. 프린터 오차는 "인쇄 위치 보정"에서 mm 단위로 맞춥니다.

수정 후 재빌드: `npm install xlsx@0.18.5 && node record-label/build.mjs`
