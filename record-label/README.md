# 기록물철 라벨 생성기

`기록물철_라벨_생성기.html`을 크롬/엣지로 열고 사업완료 명단 엑셀을 올리면
명단 순서대로 기록물철 표지·색인목록·상자 라벨을 만들어 인쇄(PDF 저장)합니다.
인터넷 연결 없이 동작하며, 엑셀 내용은 PC 밖으로 전송되지 않습니다.

- 성명 열(`성명`·`농가명`·`대표자` 등)을 자동으로 찾고, 합계 행(예: `24농가`)은 제외해 건수를 대조합니다.
- 제목 행(예: `2026년 ○○사업 사업완료내역(표선면 1차)`)에서 생산연도·사업명·차수를 읽습니다.
- 단위과제·보존기간은 화면의 "사업 ↔ 단위과제 연계표"로 자동 입력합니다. 기록관리기준표와 대조해 수정하세요.

수정 후 재빌드: `npm install xlsx@0.18.5 && node record-label/build.mjs`
